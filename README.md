## 🚀 Project Overview

**The Ultimate Excel Dashboard** is a practical e-commerce data analytics project created to demonstrate how Microsoft Excel can be used to move from **raw transactional data → data analysis → business questions → KPIs → interactive dashboard → actionable insights**.

The project is designed for **Data Analysts, Excel learners, students, freshers, and analytics aspirants** who want to practice building professional dashboards using real-world business scenarios.

The repository includes an e-commerce dataset containing transaction-level information such as products, order modes, customer demographics, locations, ratings, order dates, shipping dates, quantities, sales amounts, and delivery information.

---

## 🎯 Business Objective

The primary objective is to analyze e-commerce performance and answer important business questions such as:

* How is overall sales performance?
* Which products generate the highest sales?
* Which states contribute the most revenue?
* Which order modes are most frequently used?
* How does customer gender impact sales?
* What are the most popular products?
* How does customer rating vary across products?
* What is the average delivery time?
* Which products or locations require attention?
* How can the data support better business decisions?

The dataset contains **2,400 e-commerce transactions** with information across multiple dimensions.

| Category              | Example Fields        |
| --------------------- | --------------------- |
| 🛒 Product            | Product               |
| 👥 Customer           | Customer Gender       |
| 🌎 Geography          | State, County         |
| 💳 Order              | Order Mode            |
| 📅 Dates              | Order Date, Ship Date |
| 📦 Quantity           | Quantity Ordered      |
| 💰 Sales              | Amount                |

These fields allow the project to explore **sales performance, product performance, customer behavior, geography, order channels, and delivery efficiency**.

# 📌 Dashboard Business Questions

The dashboard is structured around practical business questions rather than simply creating charts.

### 1️⃣ Overall Sales Performance

**Question:**
What is the overall e-commerce sales performance?

**KPIs:**

* Total Sales
* Total Orders
* Total Quantity
* Average Order Value

**Recommended Visuals:**

* KPI Cards
* Monthly Sales Trend
* Sales by Product

---

### 2️⃣ Product Performance

**Question:**
Which products contribute the most to total sales?

**KPIs:**

* Sales by Product
* Quantity by Product
* Product Contribution %

**Recommended Visuals:**

* Bar Chart
* Column Chart
* Top Products Table

---

### 3️⃣ Geographic Sales Analysis

**Question:**
Which states and locations generate the highest sales?

**KPIs:**

* Sales by State
* Orders by State
* Average Order Value

**Recommended Visuals:**

* Map / Filled Map
* Bar Chart
* Geographic Ranking
